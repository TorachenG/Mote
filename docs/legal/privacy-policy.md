# Mote 隐私政策

生效日期：2026 年 10 月 22 日

最近更新：2026 年 10 月 24 日

Mote（以下称“本应用”，包名 `com.torachen.mote`）是一款开源的 Android 浏览器。本政策说明本应用会处理哪些信息、为什么处理、以及你可以如何控制。

## 一、总则

1. 浏览、书签、历史、下载等基础功能无需注册账号，也不收集你的姓名、手机号、邮箱、身份证件等身份信息。
2. 云同步是**可选功能**。只有你主动注册账号并开启同步，本应用才会把加密后的数据上传到云端；不注册账号不影响任何本地功能。
3. 本应用不集成任何广告、统计、崩溃上报或用户画像 SDK。
4. 除云同步外，本应用不会把你的浏览记录、书签、下载记录上传到任何服务器。

## 二、保存在你设备上的数据

- 设置项：外观、主页、搜索引擎、隐私开关等，保存在应用私有目录（SharedPreferences），不上传。
- 书签、历史记录、下载记录：你主动保存或产生的条目，保存在应用私有目录，不上传。
- 网页数据：Cookie、缓存、localStorage、IndexedDB，保存在系统 WebView 数据目录，仅由你访问的网站读写，不上传。
- 下载的文件：你主动下载的文件，保存在你选择的下载目录，不上传。
- 播放进度：最近播放的视频地址与进度，保存在应用私有目录，不上传。

以上数据默认只存在于本机。你可以通过「系统设置 → 应用 → Mote → 存储 → 清除数据」或卸载本应用随时删除。

## 三、账号与云同步

1. **账号**：云同步需要一个由你设置用户名与密码的账号。密码以加盐哈希（PBKDF2）形式保存，我们不保存明文密码，也无法从哈希还原你的密码。
2. **同步内容**：只有你在「同步项」中勾选的类别会被上传，包括书签、浏览历史、搜索历史、快捷网址、保存的密码、设置项。
3. **传输与存储**：同步数据先在设备上加密，再通过 HTTPS 传输，存储于腾讯云开发（CloudBase，中国上海地域）的数据库中；我们不会以明文形式存储你的同步内容。
4. **加密方式**：
   - **默认（普通加密）**：密钥由账号标识派生，用于防止同步内容被随意查看；在持有云环境管理权限的情况下，理论上仍可解密。
   - **高级数据保护（端到端加密）**：密钥仅由你的用户名与密码在设备上派生，服务端与开发者都无法解密。该模式下：忘记密码将无法恢复数据，重置密码亦无效；修改密码后，此前同步的数据需要重新同步。
5. **访问记录**：为防止接口被滥用，云函数按 IP 做频率限制，仅在短时间内保留计数；不记录你的浏览内容。
6. **删除**：在应用内退出登录不会删除云端数据。你可以注销账号，或通过下方联系方式请求删除账号及其同步数据，我们会一并删除。

## 四、无痕模式

- 无痕窗口的浏览记录不会写入历史记录。
- 退出本应用时会清除无痕窗口产生的 Cookie 与缓存（默认开启，可在设置中关闭）。
- 无痕模式只能减少本机留存，不能阻止你访问的网站、网络运营商或设备系统获知你的访问行为。

## 五、权限说明

本应用只在下述场景申请权限，你可以拒绝；拒绝后对应功能不可用，但不影响浏览网页。

- `INTERNET`、`ACCESS_NETWORK_STATE`：加载网页、检测网络是否可用、云同步。浏览网页时使用。
- `CAMERA`：扫一扫（二维码 / 条码）、拍照识别文字。仅在你主动打开扫码或拍照功能时使用。
- `RECORD_AUDIO`：网页请求使用麦克风（例如网站语音输入）。仅当网站申请且你点击允许时使用。
- `READ_PHONE_STATE`：读取当前移动网络类型（2G/3G/4G/5G），用于播放器状态显示；不读取手机号、IMEI 或通话记录。
- `READ_EXTERNAL_STORAGE`：选择本地文件上传、选择图片。仅当网页触发文件选择时使用。
- `POST_NOTIFICATIONS`：下载完成、后台播放控制的通知。首次使用相关功能时申请。
- `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK`：退到后台后继续播放音频 / 视频。
- `REQUEST_INSTALL_PACKAGES`：安装你主动下载的 APK 文件。仅在你点击安装时使用。
- `ACCESS_FINE_LOCATION`、`ACCESS_COARSE_LOCATION`：网页请求定位（例如地图网站）。仅当网站申请且你点击允许时使用。
- `CHANGE_WIFI_STATE`、`ACCESS_WIFI_STATE`、`CHANGE_NETWORK_STATE`：检测与切换网络状态。
- `VIBRATE`、`MODIFY_AUDIO_SETTINGS`：触感反馈、音量调节。

## 六、拍照与文字识别

扫一扫与文字识别使用 Google ML Kit，完全在本机离线运行：

- 相机画面与图片不会上传到 Google 或任何服务器。
- 识别结果只保存在本机内存中，除非你主动复制或保存。
- 如需停用，请勿使用该功能，或前往系统设置撤销相机权限。

## 七、第三方组件

- Android System WebView（Chromium）：负责网页渲染，由系统与设备厂商提供，受其隐私政策约束。
- Google ML Kit：条码扫描、文字识别，本机离线处理，不上传图片。
- 腾讯云开发（CloudBase）：云同步的账号、数据存储与云函数。仅在你注册账号并使用云同步时访问，且只接收加密后的同步数据。受腾讯云隐私政策约束。
- GitHub / Gitee API：检查新版本时仅发送应用版本号等公开信息；对方可能记录你的 IP 与请求时间。
- AndroidX / Media3 / Compose：界面与播放框架，不收集数据。

完整的组件与许可证清单见应用内「设置 → 法律信息 → 开放源代码许可」。

## 八、本应用不会做的事

- 不读取通讯录、短信、通话记录。
- 不读取手机号、IMEI、MAC 地址。
- 不在后台截屏、录屏或录音。
- 不篡改你访问的网页内容。广告与跟踪器拦截仅在本机按规则表阻断请求，不会修改页面。
- 不把你的任何数据用于广告投放或用户画像。
- 不在未开启云同步的情况下上传你的任何数据。

## 九、你的控制权

- 清除数据：系统设置 → 应用 → Mote → 存储 → 清除数据。
- 权限管理：系统设置 → 应用 → Mote → 权限。
- 关闭自动检查更新：应用内「设置 → 关于」。
- 无痕浏览：工具栏 → 无痕模式。
- 云同步：应用内「设置 → 同步」可退出登录、取消同步项或关闭同步功能。
- 删除云端数据：注销账号，或通过下方联系方式请求删除。

## 十、儿童隐私

本应用不面向 14 周岁以下儿童，也不会主动收集儿童的个人信息。若监护人发现相关情况，可通过下方方式联系我们删除。
