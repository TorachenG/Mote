# 用户体验改进计划

## 当前状态

**当前版本未启用任何自动数据上报，也不收集任何使用统计。**

Mote 没有集成统计 SDK、崩溃上报 SDK 或用户画像服务。你的浏览记录、书签、下载记录、输入内容都不会离开设备。

## 如果未来启用

如果后续版本引入体验改进计划，我们会遵守以下原则，并在启用前更新本页面与你看到的应用内提示：

1. **默认关闭**：必须由你主动开启，关闭后立即停止上报；
2. **最小必要**：只收集改进体验所必需的信息，例如：
   - 崩溃堆栈（不含网页地址、输入内容、文件路径）；
   - 启动耗时、页面加载耗时的匿名区间值；
   - 应用版本、Android 版本、设备型号等粗略信息；
3. **绝不收集**：浏览记录、搜索词、书签、下载内容、剪贴板、账号信息、精确位置；
4. **可随时关闭**：设置中提供开关，关闭后不再产生任何上报；
5. **可核查**：上报字段会在本页面逐项列出；
6. **限期保存**：匿名数据保留不超过 90 天。

## 你的选择

- 本页面只用于说明，当前不包含任何开关，因为尚未启用上报；
- 即使未来启用，你也可以在设置中随时关闭，且不影响任何功能使用。
