Mote 浏览器

轻快、纯净的 Android 浏览器。扫码、翻译、文档扫描、用户脚本一应俱全，开源免费。

版本 0.3.0 Android 7.0+ APK
下载最新版 GitHub 源码 Gitee 镜像

如果按钮没反应，请直接打开 Releases 页面手动下载 APK。

主要功能

冷启动更快

Baseline Profile + 启动链路优化，首屏更早出现在你眼前。

扫码 / 翻译 / 文档扫描

二维码与条码识别、整页翻译、文档增强与黑白滤镜，还能一键提取文字。

用户脚本

对标 VIA 的脚本管理：多个脚本、独立开关、在线下载与导入、@match 匹配注入。

拦截追踪

内置追踪器拦截与自定义白名单，页面更干净、加载更省流量。

阅读更舒适

夜间模式、无图模式、文字缩放与强制缩放，按站点独立记忆。

高度可定制

主页横幅、自定义背景与图片横幅、应用图标、主题色与 Material / MIUIX 双风格。

安装说明

  1. 点击上方「下载最新版」，下载 .apk 文件。
  2. 首次安装时，系统会提示「禁止安装未知来源应用」，按提示允许当前浏览器或文件管理器安装即可。
  3. Mote 完全离线可用，不需要注册账号；隐私政策见页面底部。
