Mote 书签同步：把 Mote 的书签带到浏览器。

主要功能
• 双向同步：Mote 的书签同步到 Edge / Chrome；浏览器里新增、修改、删除书签，也会同步回 Mote。
• 文件夹完整保留：Mote 的文件夹会映射为「书签栏 → Mote」下的同名子文件夹，层级不会丢。
• 两种同步方式：默认使用 Mote 云同步账号，也可以填自己的 WebDAV。
• 两种加密：普通模式由账号 ID 派生密钥；开启「高级数据保护」后为端到端加密，只有你的账号密码能在本地解密。
• 自动同步：书签改动后自动推送，并按设定间隔检查云端；也可以手动点「立即同步」。
• 只动一个文件夹：所有同步都在「书签栏 → Mote」内完成，浏览器里其它书签不受影响。

隐私说明
• 不包含任何广告、统计或分析服务。
• 账号密码、同步配置只保存在本机的扩展存储中。
• 数据只发送给你自己的同步服务（Mote 云函数，或你填写的 WebDAV 地址），不发送给第三方。
• 不使用远程代码，加密使用浏览器内置的 Web Crypto API。
