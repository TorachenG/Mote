# Mote 书签同步（浏览器扩展）

在 Edge / Chrome 与 Mote 客户端之间双向同步书签（客户端当前为 Android，后续支持更多平台）。与 App 使用同一套云同步协议：

- 云函数 `auth`（登录 / 拉取 / 推送 / 续期）
- AES-256-GCM 整包加密，自动识别「普通加密」与「高级数据保护（端到端）」

## 安装（未发布商店，本地加载）

1. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）
2. 打开右上角「开发人员模式」
3. 点「加载解压缩的扩展」，选择本目录 `extension/`
4. 点扩展图标 →「打开设置」，填写账号信息

## 配置

| 同步方式 | 需要填写 |
|---|---|
| 默认云同步 | 用户名、密码 |
| WebDAV | WebDAV 地址、用户名、密码（和 App 里填的一样） |

- 点「登录并保存」后会立即拉取一次。
- 「现在同步」用于手动触发；开启自动同步后，书签改动会在约 6 秒防抖后推送，并每隔 N 分钟检查云端。

## 同步范围

书签会放在 **书签栏 → Mote** 文件夹里。扩展只读写这个文件夹，浏览器里的其它书签不会被动。

Mote 的文件夹层级会完整保留为子文件夹。

## 行为说明

- **双向**：浏览器改动会上传，云端改动会拉下来。
- **删除会同步**：一端删掉的书签，下次同步时另一端也会删掉（用上次同步的快照判断）。
- **整包写回**：云端存的是一整份加密数据（书签、历史、设置等都在里面），扩展解密后只替换 `bookmarks_v2` 字段再加密写回，其它同步项不受影响。
- **加密模式自动识别**：先尝试端到端密钥（需要登录密码），再尝试普通密钥（由 uid 派生）。


## 多语言

界面文案走 `chrome.i18n`，词条在 `_locales/en` 与 `_locales/zh_CN`：

- 清单里的名称、描述、按钮提示用 `__MSG_extName__` / `__MSG_extDesc__` / `__MSG_actionTitle__`
- 页面里的静态文案用 `data-i18n` / `data-i18n-placeholder` 属性，由 `i18n.js` 统一套用
- 脚本里的动态文案用 `t(key, [参数])`
- 新增语言：复制 `_locales/en` 改名为目标 locale（如 `ja`），翻译后即可，无需改代码

## 已知限制

- 密码保存在浏览器扩展存储里（`chrome.storage.local`），用于自动续期与端到端解密。
- 同一时间两端同时改动同一份数据时，后写入的覆盖先写入的（没有字段级合并）。
- 若 App 端开启了「高级数据保护」，扩展必须用**相同的用户名与密码**登录才能解密。
- 若在 App 里改过密码，需要在扩展设置里重新登录一次。
